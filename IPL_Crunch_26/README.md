# IPL Crunch '26

## Overview
Data-driven analysis of IPL match outcomes using ball-by-ball historical data.

## Dataset
- Matches: 1,239
- Deliveries: 294,757

## Key Questions
1. Do teams winning the toss win more matches?
2. Which innings phase impacts victory the most?
3. Who are the top-performing batters?
4. Who are the top-performing bowlers?

## Key Findings
- Toss winners won only 50.61% of matches.
- Middle Overs showed the largest winner-loser scoring gap (7.82 runs).
- Virat Kohli emerged as the leading run scorer.
- Yuzvendra Chahal emerged as the leading wicket taker.
